### 开篇

### 起卦方式

#### 一事一卦

- 要求每次均集中意念于所卜之事，不要心存旁念，更不可以一卦内同时问卜多件事情。为什么要这样做呢？因为手摇卦区别于其余起卦方式的独特之处，就是能把问卦人的真实心态，如实反映到卦象上，所以凡是通过手摇钱币得出的卦象，都存在着一个客观的信息显示特征：“多问简显、简问多现”。意思就是说，你摇卦问事时，来去只有一个主题意念，则摇出来的卦象，它显示的信息预兆方向不单明确清晰，而且围绕着这个主题，同时会显示出跟这主题相关的其他细节信息来，这就叫简问多现。若相反，你在摇卦问事时，心思复杂，或一卦中同时问及几件事情，则摇出来的卦象，它显示的信息，反而只会简单反映几个问题之中，重要性最大的一个问题之趋势，其他相对较次要的疑惑，则会被忽略。而且因问的事情太多，细节信息显得杂乱无章，根本无法抓住各种信息的主次脉络，因此实际的预测效果反而不理想了，这就叫多问简显。故若有多事要问，则宁愿一卦完后就另一事专门再占一卦，否则卦象将飘零浑浊，更难辨别核心意念，反而影响预测的实际效果。

#### 桌面平坦

- 注意抛钱时需选择宽大平坦但不过于光滑的桌面，桌上避免摆放杂物，如在六次摇卦过程中，出现被杂物所绊不显明显背向，应立刻中止，之前所取卦象应全部作废，无故异常必有因由，勉强延续摇卦程序，则摇出来的卦象多会飘渺失准，须静心5分钟后再行重新聚思摇卦。如摇卦过程中出现某一个铜钱意外滑落地下，第一次滑落，其信息依旧可用，若第二次又再滑落，最好全部作废重新再摇；若遇上等不及的急事，可以静观其变仍取其象，但为保险起见卦成后，必须通过对证事态过去现状方式来验卦，以防止“货不对版”。

#### 时辰

- 注意若在每天的23时至0时这个时段内起卦问卜，日辰上应取下一天的天干地支。因为我们是在沿袭古代的起卦、排卦与算卦方式，而按古代时令算法，现代的当天23时至次日凌晨1时，在古代却已经是次日的子时，统取次日的日子为准，即理论上23时是古代上一天与下一天的交接点，这与现代0时为一天交接点有明显区别。而在不同的日子，日辰的天干地支也将出现差别，整个卦象系统即随之变幻，这点一定须了解。有些较专业的易学者，更会留意到现代统一时间与地方时间的时差问题，当你心中存有这个时差概念的时候，子时起卦就一定要精确到时差所在的分时；而一般人没有时差的概念，反而不需要那么精细，笼统知道23点之后为第二天日辰就行了。

### 阴阳概念

- 阳为虚阴为实、阳为简阴为繁、阳为显阴为藏、阳为刚阴带柔、阳为外阴作内、阳为男阴为女，天地相合而滋生万物，男女相合而繁殖后代，等等这些都是阴阳的客观本质。
- 《黄帝内经》对阴阳的描述观点“清阳为天，浊阴为地；阳化气，阴成形”。

#### 正确的阴阳排卦概念

- 以“**简虚为阳面，繁实为阴面**”原则来客观区分阴阳面，不能单凭主观观点或喜好臆定。以 ○ 代表阳面、● 代表阴面，正确的记爻方式如下：

| 摇钱结果 | 名称 | 记爻 | 变爻 |
| :--: | :--: | :--: | :--: |
| 三个阳面（○○○） | 老阳 | ▅▅▅▅▅ O | 变 ▅▅ ▅▅ |
| 三个阴面（●●●） | 老阴 | ▅▅ ▅▅ X | 变 ▅▅▅▅▅ |
| 一阳二阴（○●●） | 少阳 | ▅▅▅▅▅ | 不变 |
| 一阴二阳（●○○） | 少阴 | ▅▅ ▅▅ | 不变 |

- 用古铜钱起卦时，背为阳、字为阴，与上表对应关系如下：
  - 一个背、两个字，称作“单”，为**少阳**，画作“▅▅▅▅▅”。
  - 两个背、一个字，称作“拆”，为**少阴**，画作“▅▅ ▅▅”。
  - 三个背、没有字，称作“重”，为**老阳**，画作“▅▅▅▅▅ O”，变 ▅▅ ▅▅。
  - 三个字、没有背，称作“交”，为**老阴**，画作“▅▅ ▅▅ X”，变 ▅▅▅▅▅。

- 排卦过程中须特别注意以下两点：
  1. **由下向上排**：第一次摇出的爻排在最下面，依次顺序向上排列。
  2. **记爻勿凭直觉**：初学者常把 ○●● 错记成▅▅ ▅▅（少阴），把 ●○○ 错记成▅▅▅▅▅（少阳），可能因直觉上认为“那个面较多”的缘故。正确记法是：**○●● 记 ▅▅▅▅▅（少阳），●○○ 记 ▅▅ ▅▅（少阴）**，这概念须正确把握。

#### 易理演化规律与排卦方式

- 何谓阴阳互动、循环不止。以下就是其运转符号的循环转变过程：

```
○●●（少阳）→ ▅▅▅▅▅
○○●（少阴）→ ▅▅ ▅▅
○○○（老阳）→ ▅▅▅▅▅ O 变 ▅▅ ▅▅ → ●○○
●○○（少阴）→ ▅▅ ▅▅
●●○（少阳）→ ▅▅▅▅▅
●●●（老阴）→ ▅▅ ▅▅ X 变 ▅▅▅▅▅ → ○●●
……如此循环不止
```

- 这便是《黄金策》首言的：**动静阴阳，反复迁变**。尽则有变，变则无穷，“阳尽变阴，阴尽变阳”：
  - ○○○（老阳）记 ▅▅▅▅▅ O，变 ▅▅ ▅▅，即老阳变少阴 ●○○（下一变化）。
  - ●●●（老阴）记 ▅▅ ▅▅ X，变 ▅▅▅▅▅，即老阴变少阳 ○●●（下一变化）。

#### 古今钱币具体的排卦标准方式

**古币起卦**

- 明代之前铜钱，一般是一面有字一面没字：有汉字为“字”，代表阴面；无字为“背”，代表阳面。
- 清朝铜钱一面汉文一面满文：汉文为“字”，代表阴面；满文为“背”，代表阳面。
- 六次抛钱，由下至上记录（注意是北京时间）：

| 摇钱 | 记录 | 排卦标识 |
| :--: | :--: | :--: |
| 第6次抛 | （字 字 字） | 老阴 ▅▅ ▅▅ X → 变少阳 ▅▅▅▅▅ |
| 第5次抛 | （字 字 背） | 少阳 ▅▅▅▅▅，不变 |
| 第4次抛 | （字 字 字） | 老阴 ▅▅ ▅▅ X → 变少阳 ▅▅▅▅▅ |
| 第3次抛 | （字 背 背） | 少阴 ▅▅ ▅▅，不变 |
| 第2次抛 | （字 字 背） | 少阳 ▅▅▅▅▅，不变 |
| 第1次抛 | （背 背 背） | 老阳 ▅▅▅▅▅ O → 变少阴 ▅▅ ▅▅ |

**现代硬币起卦**

- 钱币应以“简虚为阳面，繁实为阴面”原则来客观区分，明确何为“阳”面，另一面则为“阴”面。

| :--: | :--: | :--: |
| 第6次抛 | （阴 阳 阳） | 少阴 ▅▅ ▅▅，不变 |
| 第5次抛 | （阳 阳 阳） | 老阳 ▅▅▅▅▅ O → 变少阴 ▅▅ ▅▅ |
| 第4次抛 | （阴 阴 阴） | 老阴 ▅▅ ▅▅ X → 变少阳 ▅▅▅▅▅ |
| 第3次抛 | （阴 阳 阳） | 少阴 ▅▅ ▅▅，不变 |
| 第2次抛 | （阴 阴 阳） | 少阳 ▅▅▅▅▅，不变 |
| 第1次抛 | （阳 阳 阳） | 老阳 ▅▅▅▅▅ O → 变少阴 ▅▅ ▅▅ |

#### 错卦正显

- 有些学易者会发现，自己以前起卦时阴面阳面的概念弄反了，或者卦排错了（由上往下排），或者把两阳一阴错排成了“少阳”。那么以前起的卦，是否全部都不能正确投影了？
- 如果你是刚学卦不久，大可放心：**一时无心之失的错排卦象，并不影响卦象的真实显像**。卦象既然什么都知道、什么都能预见，当然也能事先洞察到你的无心之失，你一时的观念错误或者失误，其实也在它预计之内了，所以自古就有“**错卦正显**”的说法。很多初学者都亲身体验过：开始学卦时卦象显示非常准确，后来深入学习才发现原来当时连卦都给排错了，但卦为什么还是能准确预见？原因就在这儿。
- 但当你认识到错误之后，**必须及时纠正自己的错误观念**。短期的错误与失误，卦象会作出迁就；长期依然保持错误方式，慢慢就会影响到断卦的准确率与稳定性，这是专门因错误排卦而造成的问题。

### 学会如何装卦

- 起卦、排卦与装卦自古以来就是一个复杂的过程。若要手工操作，须通背 64 卦象、八卦宫、五行、六亲、六神、安世应等众多六爻基础知识，正确应用才能排成一卦。

#### 装卦的具体操作流程

- 通过正确摇卦与排卦，卦象排出来如下：

```
子月庚寅日（午未空）

【本 卦】              【变 卦】
▅▅ ▅▅                ▅▅ ▅▅
▅▅▅▅▅ ○→             ▅▅ ▅▅
▅▅ ▅▅ ×→             ▅▅▅▅▅
▅▅ ▅▅                ▅▅ ▅▅
▅▅▅▅▅                  ▅▅▅▅▅
▅▅▅▅▅ ○→             ▅▅ ▅▅
```

##### 第一步：弄清楚本卦与变卦

**大白话：** 摇完卦你手里只有六条横线（阴爻或阳爻），还没有名字。装卦的第一步，就像给这六条线"贴标签"——先看下面三爻组成什么卦、上面三爻组成什么卦，两个名字一拼，就是全卦名（如下面"泽"上面"水"→水泽节）。有动爻（○或×）的，变出来的新卦也要一并认出来，后面装六亲、世应都要以本卦为主、变卦为辅。

- **八卦（八原卦）**：一卦由六个爻组成，上三爻叫上卦，下三爻叫下卦。读法由上往下读，如"地雷复"，地代表上卦、雷代表下卦，复代表上下卦组合而成的全卦名称。

**八卦速记歌：**

> 乾天坤地坎为水，离火震雷巽为风，艮山兑泽记心中。

| 乾（天） | 坤（地） | 坎（水） | 离（火） |
| :--: | :--: | :--: | :--: |
| 巽（风） | 震（雷） | 艮（山） | 兑（泽） |

- **六十四卦名**（背熟后可知各卦归属，如"水泽"是节卦，"雷水"是解卦）：

  - **乾宫**：乾为天、天风姤、天山遁、天地否、风地观、山地剥、火地晋、火天大有
  - **坤宫**：坤为地、地雷复、地泽临、地天泰、雷天大壮、泽天夬、水天需、水地比
  - **震宫**：震为雷、雷地豫、雷水解、雷风恒、地风升、水风井、泽风大过、泽雷随
  - **巽宫**：巽为风、风天小畜、风火家人、风雷益、天雷无妄、火雷噬嗑、山雷颐、山风蛊
  - **坎宫**：坎为水、水泽节、水雷屯、水火既济、泽火革、雷火丰、地火明夷、地水师
  - **离宫**：离为火、火山旅、火风鼎、火水未济、山水蒙、风水涣、天水讼、天火同人
  - **艮宫**：艮为山、山火贲、山天大畜、山泽损、火泽睽、天泽履、风泽中孚、风山渐
  - **兑宫**：兑为泽、泽水困、泽地萃、泽山咸、水山蹇、地山谦、雷山小过、雷泽归妹

**八宫变化规律（记 64 卦的窍门）：**

> 每一宫以一个纯卦为"宫头"，然后依次变初爻→一世、变二爻→二世、变内三爻→三世、变四爻→四世、变五爻→五世；再变回四爻→游魂，内卦全变→归魂。搞懂这一规律，64 卦就是 8 组重复的"家族谱"，不必逐卦死记。

**寻卦宫口诀（第三步装六亲要用）：**

> 一二三六外卦宫，四五游魂内变更，归魂内卦是本宫。

（意思是：一世、二世、三世、六世卦，卦宫就是外卦（上卦）所属的宫；四世、五世、游魂卦，需把内卦三爻阴阳全变后再看属哪宫；归魂卦则内卦就是本宫。）

##### 第二步：为卦象装上地支

**大白话：** 光有阴阳横线还不够，得给每一爻配上"五行属性"才能论生克。古人用十二地支（子丑寅卯……）给每爻贴五行标签，这套规则叫"纳甲"或"浑天甲子"。打个比方：六爻像六个人，纳地支就是给每人发一张身份证，上面写着他是属金、属木还是属水——后面论六亲、论旺衰全靠这张证。古法也配天干，但实践证明**只用地支就足够准确**，所以现代六爻一般省掉天干，省事不少。

- 先背熟八个原卦所配套的地支，古谓之"**浑天甲子**"。浑天甲子原是天干地支相匹配，然而一卦之中既论天干生克又论地支生克，何其繁复；经历代易学先贤筛验，**单以地支论吉凶已经足够保证准确预测**，故而舍去天干。理论多并非就一定好，关键是能否相互融合。

**纳甲总原则：阳卦顺行，阴卦逆行。**

- 阳卦（乾、震、坎、艮）：地支按子→寅→辰→午→申→戌顺序**顺数**。
- 阴卦（坤、巽、离、兑）：地支按未→巳→卯→丑→亥→酉顺序**逆数**。

**纳甲歌（八纯卦完整版）：**

> 乾金甲子外壬午，坎水戊寅外戊申。  
> 艮土丙辰外丙戌，震木庚子外庚午。  
> 巽木辛丑外辛未，离火己卯外己酉。  
> 坤土乙未外癸丑，兑金丁巳外丁亥。

（每句前半为内卦/下三爻，后半为外卦/上三爻；如"乾金甲子"=乾卦内卦从子起顺排子寅辰。）

> 震在内子寅辰，震在外午申戌。

##### 第三步：为卦象配装上六亲

**大白话：** 六亲不是真正的亲戚，而是给六爻起的"角色名"——父母、兄弟、子孙、妻财、官鬼，本质上是五行生克关系的代号。装六亲时，先把本卦所属的**卦宫五行**当作"我"（本家），再看每一爻的地支五行与"我"是什么关系：生我的叫父母，我生的叫子孙，克我的叫官鬼，我克的叫妻财，同类的叫兄弟。好比一个水命人（坎宫属水）看六个陌生人：属水的叫兄弟，属金的叫父母（金生水），属木的叫子孙（水生木），属土的叫官鬼（土克水），属火的叫妻财（水克火）。

**六亲定位口诀：**

> 生我者父母，我生者子孙；  
> 克我者官鬼，我克者妻财；  
> 比和者兄弟。

**六亲象义速记（方便理解，非定死）：**

| 六亲 | 常见代表 |
| :--: | :-- |
| 父母 | 长辈、文书、合同、房屋、车辆、保护 |
| 兄弟 | 同辈、竞争者、同伴、破费、分财 |
| 子孙 | 晚辈、成果、医药、解忧、玩乐、财源 |
| 妻财 | 钱财、物品、资源、女友、饮食 |
| 官鬼 | 工作、压力、疾病、忧患、男性、官非 |

**八卦宫五行歌：**

> 乾兑属金坎属水，离火震巽都是木，艮坤两宫属为土。

- 要为卦象装六亲，首先要了解本卦属于哪个卦宫、属性是什么：

| 卦宫 | 属性 | 所属八卦 |
| :--: | :--: | :-- |
| 乾宫 | 金 | 乾、姤、遁、否、观、剥、晋、大有 |
| 坤宫 | 土 | 坤、复、临、泰、大壮、夬、需、比 |
| 震宫 | 木 | 震、豫、解、恒、升、井、大过、随 |
| 巽宫 | 木 | 巽、小畜、家人、益、无妄、噬嗑、颐、蛊 |
| 坎宫 | 水 | 坎、节、屯、既济、革、丰、明夷、师 |
| 离宫 | 火 | 离、旅、鼎、未济、蒙、涣、讼、同人 |
| 艮宫 | 土 | 艮、贲、大畜、损、睽、履、中孚、渐 |
| 兑宫 | 金 | 兑、困、萃、咸、蹇、谦、小过、归妹 |

- 本卦"节"属于**坎宫**，性质属**水**。
- 五行生克（顺位相生，隔位相克）：金生水、水生木、木生火、火生土、土生金；金克木、木克土、土克水、水克火、火克金。
- 六亲理论：生我者父母，我生者子孙，克我者官鬼，我克者妻财，同类者兄弟。
- 将主卦节的五行性质代入为"我"，"我"属水，然后将"我"与卦中各地支按六亲关系配上去。如子水与"我"同属性，为**兄弟**；戌土克水，克我者官鬼，为**官鬼**，如此类推。
- **务必记住：变卦的五行属性跟随本卦**，不再有自己卦宫的独立属性。变卦的六亲仍按本卦（坎宫水）来推，不能按变卦的新卦形另算卦宫。

##### 第四步：为卦象装上世应

**大白话：** 六爻卦里有两个特殊位置——**世爻**代表问卦人自己，**应爻**代表所问之事或对方。定世应不用逐卦死记，而是看本卦与所属纯卦（宫头卦）相比，哪一爻变了、变了几次，世爻就落在相应位置。应爻永远在世爻**往上数三位**（中间隔两爻），比如世在初爻，应就在四爻；世在五爻，应就在二爻。

**天地人定位（装世应的核心概念）：**

| 位置 | 对应爻位 | 俗称 |
| :--: | :--: | :--: |
| 天 | 三爻、六爻 | 天爻 |
| 人 | 二爻、五爻 | 人爻 |
| 地 | 初爻、四爻 | 地爻 |

**装世应口诀：**

> 天同二世天变五，地同四世地变初；  
> 本宫六世世三异，人同游魂人变归。

（天同二世：天爻相同、其余相反→二世卦，世在二爻；天变五：天爻变了、其余相同→五世卦，世在五爻；地同四世、地变初、本宫六世、三世异、人同游魂、人变归，同理类推。）

**快捷版（配合卦序使用）：**

> 一世初、二世二、三世三、四世四、五世五、六世六；  
> 游魂世在四，归魂世在三。

**安应爻口诀：**

> 若问应爻安何处，世隔两爻即为应。

### 完整断卦步骤

> 追源：[古筮真诠·总论篇]第八章：完整的断卦步骤（[赵Sir的Blog](https://zhaosir.online/Books/BookChapterDetail.aspx?did=645) · B站：朱辰彬国学智慧）

#### 古筮分析要明白的道理

**两种常见误区：**

- **信者的宿命论**：因经历预测准确，便认为未来一切早已注定、人力难以改变。
- **不信者的否定论**：认为未来完全不可知，算卦是无凭无据的胡说。

**正确的认识：**

- 未来是**变数而非定数**，不存在永久不变的宿命；人的主观意识与行为改变，都会随时改变未来际遇。
- 未来也不是毫无规律的乱变，它是在过往与当下某些条件积累下，继续延伸形成的**有限惯性演变**——所以未来可以有限度地预见。
- 古筮预判的不是"宿命定数"，而是**当前条件下未来趋势的惯性延伸**；趋吉避凶的思路，也应从认知并改变过去、现状的条件入手。
- 毫无事实依据的预判，难免有胡说八道之嫌。古筮至少应能把与未来相关的**现状信息**解读出来，与客观事实逐一对证——对得上，后续分析才站得住脚。
- 无论技巧多熟练，**不可能长期 100% 准确**（如同卫星发射也可能偏轨）。古筮预测**只能作参考，不能替代决策**。

**六爻预测的能力边界（传统共识，宜心中有数）：**

- 六爻反映的是事物**在特定条件下的吉凶轮廓**，擅长明阴阳、示吉凶，而非事无巨细地还原全部细节。
- 卦象信息有**阶段性**：测哪段事，显哪段吉凶；阶段范围由求测者意念控制，不能无限前推后延。
- 传统文献强调"有条件、有前提"才能下断语，**无条件的"必成""无疑"式断言并不可取**（同上前引）。
- 上述边界与"未来可有限预见"并不矛盾：预见的是**趋势惯性**，不是全息录像。

#### 对轨与预测：总体程序

**大白话：** 断卦就是按系统有序的易理，结合事情的现实特征，从卦里读出综合信息，勾画出事态的"虚拟运行轨迹"。这条轨迹分两半：

| 部分 | 名称 | 内容 |
| :--: | :-- | :-- |
| 已发生的 | **对轨** | 事态的过去与现状 |
| 未发生的 | **预测** | 未来趋势的惯性推演 |

**为什么要先对轨？** 好比卫星发射：先用公式虚拟出全程轨道，再与已飞行的数据对接、纠正偏差，然后才推测后续轨道。卦象里的现状信息若与事实**完全对接**，等于已掌握轨迹的一半规律，再推未来更有把握；若对不上，则对预兆数据应**持谨慎保留态度**。

古筮这种"**对轨 + 预测**"的程序，体现了其严谨性——不需要事先了解事态详细过程，但卦中显示的过去、现状部分，应能与客观事实对应，眼见为实，再加上预测效果，才足以证明其科学性。


**两大理论层面的交互：**

- 卦象如同**镜子**，信息是现实景象的投影；同一卦象因所问不同，各有所指。完整分析 = **卦象虚拟信息** + **事情实体信息** 的虚实对应与融合。
- **细节层面对轨** → 主导 **吉凶层面** 的用神等定位（专业者称"**客观取用**"：结合现状特征，判断哪一爻对应现实中哪一角色）。
- **吉凶层面对轨** → 主导 **细节层面** 的思路展开（"吉断有吉应，凶断有凶应"即两层面关系的体现）。
- 初学者可暂用**主观取用**（按问事类型套公式找用神），待基础扎实后再进阶客观取用。

**对轨的操作要点与甄别（避免误用）：**

| 可信做法 | 需谨慎的做法 |
| :-- | :-- |
| 就所问之事核对关键现状信息是否吻合 | 对不上轨就断定"卦错"或"问者撒谎" |
| 核心信息对轨即可，不要求面面俱到 | 把对轨当作炫技或包治百病的万能钥匙 |
| 对轨不上时，对预兆持保留态度 | 自己定义卦意，再反过来指责卦主口是心非 |
| 一事一占、问句清晰后再对轨 | 多问混杂、问句模糊时强行对轨 |

> 对轨目的是**验证卦象与所问之事的对应关系**，确立正确思路；须灵活运用，不能机械化。

#### 完整断卦七步骤

##### 1. 实证对轨

- **简称：对轨。** 一卦显一事，卦中既含吉凶应期，也含过去、现状的蛛丝马迹。真卦必藏与事实对应的轨迹信号，可从中模拟现状，再与客观现实逐一对证，排除假卦或假显，提高预测准确率。
- 对轨往往是预测中最先向求测者陈述的内容——不是断卦人"透视"，而是**把卦里已有的信息读出来**；这也是验证卦象真实性的必须流程。
- **心念爻**：卦中专门反映求测者心理变化的信息点，是探秘心念的钥匙。功力深者还可核实求测者真实心态是否与所问之事吻合。
- **三种常见错位：**
  - **口心一致**：口中所问即心中所想。
  - **问非所问**：口中所问，并非心中真正所念。
  - **答非所问**：卦象显示的内容，并非求测者心中所问之事。
- **推测来意 vs 核实来意：** "对方不言即测来意"把握往往只有十之五六，不可作通用技能；**核实来意**（对方已言明何事而来）信息面收窄、判别更清晰，属技术可控范畴，应系统掌握。把握真实意图或卦象真实显示内容，是抓住轨迹要害、提高准确率的关键。
- **对轨前的问卦纪律（影响对轨成败）：** 问句质量往往决定用神能否立住——宜**一事一问**、主语清楚、时间边界明确、成功标准可验证；多问捆绑或问句含混，卦象易"漂移"，对轨与取用神都会困难。

##### 2. 明确用神

- **简称：定位。** 将要问的事代入卦中某一爻，此爻为**用神**；占卦人代入某一爻，此爻为**世爻**（排卦时已定）。通过动爻围绕世、用生克冲合，综合旺衰与关系，预测未来趋势。
- **动必有因**：爻不会无缘无故发动，动爻必有明确指向，专门围绕**世爻或用神**转动——如同月亮绕地球、地球绕太阳，有目标的运动，不会乱转。
- 不定用神，就如地球不知太阳在哪，整个卦象失去分析核心。
- **世爻 ≠ 用神**：世爻代表自己，是分析立足点；用神代表所问之事，须按问事类型另行确定。二者有时重合，不可默认等同。
- **业余者**：首要任务是寻找并明确用神（多用**主观取用**——按通表公式定位）。
- **专业者**：除用神外，还需定位动爻、变爻、应爻意象、日月卦辞的现实寓意等；且各元素定位不应生硬套公式，而应在**对轨基础上**，以卦象对应实象的客观思维，明确其事实上可能的身份。这种从业余到专业的演变，需循序渐进，不可跳过基础。

**主观取用速查表：**

| 占问事项 | 用神 | 备注 |
| :-- | :-- | :-- |
| 求财、生意 | 妻财 | 兼看子孙（财源） |
| 求职、升职、工作 | 官鬼 | 兼看父母（单位、文书） |
| 考试、合同、证件 | 父母 | |
| 子女、宠物、医药 | 子孙 | 测病时子孙亦为"药" |
| 婚姻（男问） | 妻财 | 兼看世应 |
| 婚姻（女问） | 官鬼 | 兼看世应 |
| 出行、搬迁 | 父母 | 亦看世应 |
| 疾病 | 官鬼（病）、子孙（药） | 双用神 |
| 合作、对方态度 | 应爻 | 兼看相关六亲 |
| 失物 | 妻财或父母 | 视物类而定 |

> 《增删卜易》："用神乃一卦之主宰，不可不先看用神。"

**用神不上卦时的取用顺序（传统定法，须严格按序）：**

1. 主卦中找用神
2. 变卦中找用神
3. 日月建上找用神（日月临用神五行/六亲）
4. 以上皆无，方从本宫首卦套出**伏神**，并重点分析**飞神**与伏神的关系

- 用神不上卦本身值得警觉：可能问非所问、心态变化，或卦象将显另兆；但依规则寻伏神后仍须正常分析，不可简单视为"事不存在"。
- **用神多现**：主卦或变卦出现多个同类用神时，取旺相有气、与世应位置相关者优先，不可随意挑选。

##### 3. 吉凶定性

- **简称：定性。** 明确用神后，围绕用神与世爻，运用吉凶判断层面的逻辑与公式，综合旺衰与彼此关系，判断事情成败吉凶方向，以及对自身的利弊。此步骤运用的套路统称"**吉凶判断层面知识**"，是六爻理论中最核心、最严谨、最有序的部分。
- 人们占卜，无非想预知成败祸福以便应对，故此步是检验卦占成败的**最关键环节**。

**旺衰判断四层（断吉凶的操作骨架）：**

| 层次 | 内容 | 大白话 |
| :--: | :-- | :-- |
| 1 | 月建（月令） | 大环境、根本；主旺相休囚 |
| 2 | 日辰 | 当下即时力量；可暗动、日破 |
| 3 | 动爻、变爻 | 变化的枢纽；回头生克、进退 |
| 4 | 卦中其他爻 | 生扶克泄、合冲刑害 |

- **日月为根**：用神得日月之一生扶比助则有根；日月皆克且无解救，多主凶（传统六爻共识）。
- **吉凶判断通则**（《易隐》等）：用神旺相、忌神衰弱则趋向成事；用神衰弱、忌神旺相则趋向不利——须结合动爻、世应、卦局综合判断，不可单看一句口诀。
- **动爻为吉凶枢纽**：静卦重用神与日月；动卦须重点看动爻对用神、世爻的生克冲合及化进神、化退神、回头生克。

##### 4. 应期推测

- **简称：应期。** 在吉凶已有明确方向的前提下，以应期专用卦理，推测吉凶最可能发生的**时间段**。
- 吉凶判断正确是重中之重；**应期圈定时间范围**，则大幅提高趋吉避凶的可行性，是专业预测的重要特征之一。
- **应期不能脱离吉凶单独推**：先判"会不会发生"，再判"什么时候发生"（六爻断卦通行顺序）。

**应期常用方法（《增删卜易》："应期之法，全在生旺墓绝、冲合填实"）：**

| 方法 | 适用情形 |
| :-- | :-- |
| 用神逢值/逢合 | 用神临其地支或合局之时 |
| 用神逢冲 | 静爻逢冲则动；合处逢冲 |
| 空爻填实/出空 | 旬空之爻待出空、填实 |
| 破爻逢补 | 月破、日破待合补之期 |
| 墓爻逢冲 | 入墓者待冲墓；过旺者待入墓 |
| 动爻应期 | 动爻逢值、逢合、逢冲之日 |
| 长生十二宫 | 用神长生、帝旺、墓、绝等阶段 |

**应期时间尺度：**

| 问事跨度 | 应期侧重 | 对应细节层面公式 |
| :--: | :-- | :-- |
| 短事（约一月内） | 以日为主 | 日转月不转 |
| 常事（约一年内） | 以月为主 | 月转日不转 |
| 长事（一年以上） | 以太岁为主 | 日月皆不转，只有太岁动 |

- 事情尚未成熟时，不宜强行压到具体某日；先看条件是否具备，再推触发时间。

##### 5. 细节铺开

- **简称：细节。** 吉凶定性与应期估计之后，进一步模拟事态的各种细化演变。所用理论最广、思路最灵活，最考究博学、创意、社会阅历与实战经验。
- **业余与专业的分水岭**：业余者往往只能"知其然"（有效预见）；专业者"知其所以然"（有效趋吉避凶），关键差别就在细节解读的放大能力——从准确把握现状点出发，再延伸到各类细节铺开。
- 易理掌握有限则思路蔽塞；缺乏举一反三则无法从有限易象演化无限实像；社会阅历浅薄则纸上谈兵。细节精通需数倍于初学者的进修精力。

##### 6. 事外解读

- **简称：兼象。** 一卦信息包罗万有：与事件直接/间接相关的过往将来信息；也可能含与所问无关、但与事主损益密切相关的**短期其他重要预告**——称"**事外信息**"。
- 有的卦还预告事件**完结之后**更往后的趋势演变，称"**事后信息**"。
- **重要原则：** 事外、事后解读**不是主观想断就断**，须严格依据卦象发出的**特定信号**；反对喧宾夺主式的一卦多断——不是你想说什么，卦里就有什么。

##### 7. 趋吉避凶

- **俗称：化解。** 筮法终极目标不是仅预见未来，而是在正确了解未来惯性轨迹的基础上，通过人为努力，改变不利趋势或加速有利趋势。
- 化解须建立在对**现状特征、定位定性、应期细节**全面解读之上，站在事实与数据基础上展开补救。
- **就事论事：** 最具备实效的化解策略，一定与**事情本身的变化**相关；与事情全无瓜葛的摆物品、做法事、画符等，大多是无效花招。
- **化解原理：** 找到轨迹惯性形成的关键点，改良该点的现状条件，从而改变整个未来方向。未来是变数——古筮预见的是**当前条件下的趋势惯性**，条件变了，惯性影像随之而变。
- **客观限制：** 并非所有惯性轨迹都能人为改变。条件尚不稳固的较易改；已根深蒂固的（如加速行进中的车）较难改。能正确预见趋势，已等于掌握一半主动。
- **化解≠风水摆设：** 传统文献中的化解思维，核心是**改变事件本身的条件与行为**（如直接找关键人物摊牌、调整策略、把握应期窗口等），而非与事无关的仪式性操作。

#### 断卦常见误区（理论混用是失准主因）

| 误区 | 正确做法 |
| :-- | :-- |
| 吉凶层面与细节层面规则混用 | 先定层面，再选对应规则；**同一符号在两层面含义可完全不同** |
| 未取用神就论吉凶 | 凡断卦必先取用神 |
| 未断吉凶就推应期 | 先定性，再应期；吉断循吉应，凶断循凶应 |
| 把世爻直接当用神 | 世为自己，用神为所问之事，须分而视之 |
| 初学硬走七步、理论杂糅 | 先掌握三步，层次分明后再进阶 |
| 同一事连摇多卦挑顺耳的 | 破坏一事一占，用神与对轨皆失真 |
| 无条件的"必成""无疑" | 须结合条件与层次，留有余地 |

**同一理论、不同层面——典型差异（理论说明，无案例）：**

- 某动爻在**吉凶层面**明动遇日冲：动不为真破，仍可生旺用神，吉兆定性成立。
- 同一动爻在**应期层面**：毕竟暂时受日冲散，须待补破、出空或填实之期，吉兆方可作实。
- 这说明：**吉凶定方向，应期定时间**；二者用同一"日破"符号，解读目的不同，结论层次不同。

#### 七步骤与两大理论层面的关系

| 步骤 | 简称 | 主要运用层面 | 对轨/预测 |
| :--: | :-- | :-- | :-- |
| 1 实证对轨 | 对轨 | 应期细节层面 | 对轨 |
| 2 明确用神 | 定位 | 应期细节层面 | 对轨 |
| 3 吉凶定性 | 定性 | **吉凶判断层面** | 预测 |
| 4 应期推测 | 应期 | 应期细节层面 | 预测 |
| 5 细节铺开 | 细节 | 应期细节层面 | 对轨 + 预测 |
| 6 事外解读 | 兼象 | 应期细节层面 | 对轨 + 预测 |
| 7 趋吉避凶 | 化解 | 应期细节层面 | 预测 |

- **七步之中，仅第 3 步"吉凶定性"运用吉凶判断层面知识；其余六步均运用应期细节层面知识。**
- 完整推算 = **对轨** + **预测** 两部分综合构成；第 1、2、5、6、7 步侧重对轨，第 3、4、5、6、7 步涉及预测。
- **实证（对轨）的意义：** 要更精确、要证明科学性、要争取社会认可，都离不开对轨。历史上多数论著偏重"如何预测"，而"如何解读过去现状"的理论相对匮乏，导致古筮易被归为玄学。**只懂预测、不懂对轨，属于不全面的轨迹模拟**，直接影响准确性与稳定性。

**如何判断预测者是否靠谱（大白话）：**

> 不必看名头多大，只听他对**已知或现存的过去、现状**有什么说法。未来没到那天谁都说得清；若他能点中部分已知事实，说明已正确把握轨迹的一部分，其对未来预见就更值得重视。真才实学者不惧怕实证，甚至会主动求证——不是为了摆显，而是排除虚假信息、确立正确思路。滥竽充数者则往往回避实证。

#### 初学者适用三步骤

**为什么初学者不必强求七步？** 完整七步要求"专业"水准，需常年知识积累、实战经验与社会阅历，一般难在十年八年内娴熟运用。初学硬走全流程，易致理论层次混乱、欲速不达——各类相互排斥的理论杂糅乱用，往往"往哪个方向都能自圆其说"，实践时却不知选哪条路，反而连卦都不会断。

**初学者只要求三步：**

| 顺序 | 步骤 | 要点 |
| :--: | :-- | :-- |
| 1 | **取用神** | 先找到问事的核心爻 |
| 2 | **断吉凶** | 判断成败祸福方向 |
| 3 | **推应期** | 推测何时应验 |

**为何必须先取用神？**

- 动爻有明确指向，非用神即世爻。世爻排卦已定，关键在找到用神。
- **同一卦，用神不同，吉凶方向可以截然相反**——不明用神，就不知动爻动的真正目的，无法洞悉卦机。故**凡断卦，必先取用神**。

**为何必须先断吉凶、再推应期？**

- 应期有普遍原则：**"吉断有吉应，凶断有凶应"**。应期不能独立分析，必须在吉凶定性前提下展开——吉断则循吉利思路找应期，凶断则循凶险思路找应期。
- 吉凶定性不同，同一卦的应期推断方向可以完全不同；甚至动空、冲空等细节，也须服从吉凶主线（如凶断时，冲空可能令忌神实而发力，不能简单选为应凶日）。

**初学者断卦操作顺序（可对照三步执行）：**

```
明确问句 → 取用神 → 看日月旺衰 → 看动变与世应 → 断吉凶 → 推应期
```

- 静卦以用神与日月为主；动卦须重点看动爻对用神的作用。
- 吉凶与应期掌握娴熟后，再逐步加入对轨、细节、伏神、六神、星煞等进阶内容。

**进阶路径：** 三步运用娴熟、把握自如后，再逐步尝试对轨、细节、事外、化解等进阶内容。基础理论须一步一个脚印，根基扎实，水平才有实质提升。

### 两个理论层面

> 追源：[古筮真诠·总论篇]第九章：断卦须区别分析的两个理论层面（[赵Sir的Blog](https://zhaosir.online/Books/BookChapterDetail.aspx?did=646) · B站：朱辰彬国学智慧）

#### 为何必须先认识两个层面

- 六爻理论五花八门，**层次清晰是准确断卦的必要前提**。许多学者苦学多年、博采各说，准确率却始终上不去，多半是因为**搞不清各理论的适用范围**，理论用错地方——如同用柴刀剖牛、用耕车搭货，效果自然大打折扣。
- 古筮六爻的分析思维，据朱辰彬体系，由两个基本层面组成：
  - **吉凶判断层面**（简称**吉凶层面**）：定成败祸福方向。
  - **应期细节层面**（简称**细节层面**）：定时间、现状、过程、细节及趋吉避凶。
- **两层关系：** 细节层面对轨 → 为吉凶层面定用神（客观取用）；吉凶层面对性 → 为细节层面定应期与细节思路。两层**不可混用规则**，否则是失准主因（详见上文「断卦常见误区」）。

**一句话记忆：吉凶定方向，应期定时间；先定层面，再选规则。**

---

#### 四个方面的特征区别

##### （1）分析目的不同

| 层面 | 目的 | 大白话 |
| :--: | :-- | :-- |
| 吉凶层面 | 分析与鉴别卦象的**吉与凶** | 这事成不成、利不利 |
| 细节层面 | 剖析**时间、现状、过程、细节、事后信息**及趋吉避凶 | 何时成、怎么成、现状如何 |

- 同一符号可以服务不同目的，解读结论因此不同——这是两层区分的根本（详见下文对照表）。

##### （2）完整卦象定义不同

**完整卦象** = 卦象本身 + 日令月令组合。两层因目的不同，所要求的"完整卦象"也不同：

| 项目 | 吉凶层面 | 细节层面 |
| :-- | :-- | :-- |
| 日月 | 月柱 + 日柱 | 年 + 月 + 日（三柱齐全） |
| 本卦 | 显示 | 完整显示 |
| 变卦 | **只写动爻**，静爻不显示 | **不管动否，完整显示** |
| 伏神 | **不属于卦象**，仅作用神备选时套算添上 | 与用神相关时须标示 |
| 藏爻 | 一般不显示 | 有作用时须显示 |
| 六神、星煞 | 一般不标示 | 详细排列 |
| 卦宫 | 需要 | 需要 |

**吉凶层面卦象示例（精简写法）：**

```
干支：未月 辛丑日（旬空：辰巳）
泽山咸 → 天山遁

【本 卦】              【变 卦】
▅▅ ▅▅ 父母未土 应×→   ▅▅▅▅▅ 父母戌土
▅▅▅▅▅ 兄弟酉金
▅▅▅▅▅ 子孙亥水
▅▅▅▅▅ 兄弟申金 世
▅▅ ▅▅ 官鬼午火
▅▅ ▅▅ 父母辰土
```

**细节层面卦象示例（完整写法）：**

```
干支：丙子年 乙未月 辛丑日（旬空：辰巳）
神煞：禄神—酉 羊刃—申 ……（逐项排列）
兑宫：泽山咸    乾宫：天山遁

六神  伏神   【本 卦】           【变 卦】
……（六爻俱全，含伏神、变卦静爻）
```

**关键原则：**

- 吉凶层面**不包含变卦中静止的爻**——某爻若在变卦中但属静爻，吉凶定性时卦面上"不存在"，只在细节剖析时才用得着。
- 伏神在吉凶层面**本不存在**；用神不上卦时，才通过本宫首卦套算伏神作备选，并应引起警觉（问非所问、心态变化或另兆显现）。
- 若不清晰各层面卦象应包括/不包括哪些元素，分析必然混乱。

##### （3）应用理论特点不同

**吉凶层面：严谨细致、泾渭分明**

- 各式理论定义严格，**丝毫不能混淆**，如钟表齿轮，凸凹必须咬合。
- 动爻何时有用、何时无用，有严格规范。
- 遍布鉴别套路：**真空假空、真破假破、真墓假墓、真进假退、真绝假绝**等。

**细节层面：灵活飘逸、择象套用**

- 日月、五行、六亲、天干、地支、六神、星煞、卦辞、卦宫、十二宫等，几乎**每个符号都可多层含义**。
- 根据事情客观状态灵活择象；吉凶层面不允许的**月墓、月绊、月刑**等，细节层面可按需运用。
- **卦理须迁就事理**：同一动爻在细节上可有不同解读方向，须结合事主现实状态定夺，方称客观分析。

**吉凶层面 vs 细节层面——常见规则对照表：**

| 理论符号 | 吉凶层面 | 细节层面 |
| :-- | :-- | :-- |
| 动爻逢日冲 | **动不为真破**，仍可按有用动爻论 | 仍算有破绽，待补破/填实之期应事 |
| 动爻旬空 | **动不为真空**，按不空论 | 仍算空，待出空/填实之期应事 |
| 静爻逢日冲 | 旺则**暗动**，衰则**日破** | 关注冲的动向与时间 |
| 爻逢月冲 | 一律**月破**（高层次衰败） | 月破为真破，待出月/填实/合局转机 |
| 日墓 | 有（从于卦理） | 可用 |
| 月墓 | **不存在** | 可用（如"住院""被困"等现状） |
| 日绊（动合） | 有，主拖延 | 可用 |
| 月绊 | **不存在**，月合只论旺相 | 可用 |
| 日月相刑 | **不存在** | 可用（如病痛、隔膜等细节） |
| 月令对爻 | 仅**旺相休囚** | 可用生旺墓绝 |
| 日令对爻 | 有**生旺墓绝**，但从于卦理 | 灵活套用 |
| 爻克日月 | 可论爻在月令**休囚** | — |
| 爻克日月 | **不可**论爻在日令休囚 | — |
| 变卦静爻 | 吉凶卦面**不存在** | 完整参与分析 |
| 退神动爻 | 吉凶层面可判**无用** | 细节层面仍可读象 |
| 日月组合 | **日月同功同权**（针对吉凶） | 转换规则另有一套（见下） |

**同一理论、两层含义——典型差异（理论说明）：**

- 动爻明动遇日冲：吉凶层当它**不破**，仍可生旺用神 → 可定吉；细节层仍视其**暂时受冲散** → 应期待补破之期。
- 用神遭月"墓"：吉凶层**不论入墓**（月令无生旺墓绝）；细节层可论**住院、被困**等现状。
- 静爻得日合：吉凶层视为**合起显旺**；细节层还可读合的具体时间与过程。
- 判断日月合还是克：吉凶层须**对应现状**——若日月克伤用神，现实中必有对应病症/不利事实；若无，则论合不论克。

##### （4）分析时态不同

**吉凶层面 = 静态分析（即时点分析）**

- 从摇卦成卦那一刻起，**定格**在成卦时的日月与卦象上分析吉凶。
- 日月**不随**预后时日变换而转动。
- **禁止**将事情发生日的日月套入吉凶分析，或将起卦日与发生日两种日月分别分析再综合——程序繁复且无实际效用，等于自寻烦恼。
- 例：子月子日占问丑月丑日之事，吉凶只按**子月子日**定格定性，不因事情在丑月丑日发生而改换日月。

**细节层面 = 动态分析**

- 推演应期与细节时，卦中日月须**随时日推移而变换**，才能预判吉凶发生的具体时日。
- 变换运算与日常万年历略有差别，简易公式：

| 问事类型 | 时间跨度 | 日月转换口诀 |
| :--: | :-- | :-- |
| 短事 | 约一个月内 | **日转月不转** |
| 常事 | 约一年内 | **月转日不转** |
| 长事 | 一年以上 | **日月皆不转，只有太岁动** |

- 应期公式（如"爻动逢值逢合为应期"）的形成原理，正与上述日月转换有关；理解原理比死记公式更重要。
- 实际断应期可套公式，不必每次都繁琐推算日月轨迹，但须知晓来龙去脉。

#### 两个层面的依存关系

两个层面特征有别，却**紧密联系、互为牵引**，在预测一件事的过程中交错展开：

```
细节层面对轨（现状信息）
        ↓ 主导
吉凶层面定位（用神等）→ 主观取用（初学）/ 客观取用（专业）
        ↓ 主导
吉凶层面定性（吉或凶）
        ↓ 主导
细节层面铺开（应期、过程、细节、化解）
```

| 阶段 | 主导层面 | 角色比喻 |
| :-- | :-- | :-- |
| 开始对轨 | 细节层面 | 定角色、定用神（客观取用） |
| 吉凶判断 | 吉凶层面 | **点与主干** |
| 应期细节 | 细节层面 | **面与支节**（须在吉凶前提下展开） |

- 卦象如**镜子**，信息是现实景象的投影；同一卦象因所问不同，各有所指。
- 完整分析 = **卦象虚拟信息** + **事情实体信息** 的虚实对应与融合。
- **客观取用**：专业者通过对轨，结合现状特征定位用神；初学者可暂用**主观取用**（按问事类型套公式），待基础扎实后再进阶。
- **吉断有吉应，凶断有凶应**：应期分析依赖吉凶定位——吉断则找用神得生旺之期，凶断则找忌神发力或生路被断之期。

**分析主线建议：** 分开两个层面，**以点带面**，沿核心线索逐层展开——先吉凶主干，再细节枝叶，主线才清晰有序。

#### 各理论在两个层面的应用分类

| 分类 | 代表理论 | 说明 |
| :--: | :-- | :-- |
| **多数仅吉凶层面** | 四时旺相休囚 | 月令旺相休囚死的定法 |
| **多数仅细节层面** | 相害、相刑、星煞、六神、三会局、应爻、世应关系 | 细节、应期、现状、心态解读 |
| **两层面都有，用法不同** | 生旺墓绝、旬空、暗动、三墓、三绊、动爻作用方向 | 须先定层面再应用 |
| **同爻不同用** | 用神 vs 应爻 | 用神主吉凶判断；应爻多运用于细节/应期 |

- 掌握任何理论套路，须清楚：**用在哪个层面？同一理论在不同层面如何运行？**
- 初学不必一次吃透全部对照，**先建立"两层意识"**，随各篇章深入再逐步细化。

#### 日月在两层中的特殊说明

> 参考：[易象乾坤·日月区别](https://www.yixiangqiankun.com/823.htm) · [易师汇·日月旺衰](https://ly.yishihui.net/18508.htm)（与古筮真诠体系一致者采信）

**吉凶层面——"日月同功同权"：**

- 日月对卦中各爻地位平等，共同构成外部影响环境。
- 此说**专门针对吉凶层面**；到了细节层面，日月转换另有说法，须概念清晰。

**吉凶层面——日月作用异同摘要：**

| 现象 | 月令 | 日令 |
| :-- | :-- | :-- |
| 冲动静爻 | 无此功能；逢冲即**月破** | 旺则暗动，衰则日破 |
| 合住动爻 | 只论**旺相** | 论**绊**（拖延） |
| 生旺墓绝 | **不存在** | 存在，从于卦理 |
| 旺相休囚 | **存在** | 不存在（用生旺墓绝等） |

- 生旺墓绝在日令的应用原则：**爻旺者附旺，爻衰者附衰**——是否论长生/帝旺/墓/绝，须看爻的综合旺衰，不可机械套用。

#### 两层规则精要

##### 吉凶层面

- 吉凶判断层面的理论，目的就是用于分析卦象的吉凶成败趋势，为的是准确把握事态的祸福预兆方向，简单概括就是为了分析与鉴别卦象的吉与凶
- 应用于吉凶判断的完整卦象，只有日月组合、主卦与变卦；只写动爻，不变的爻不用显示，伏爻并不属于卦象一部分，只有作为用神备选的时候才通过套算添加上去，除非要作为用神，一般不用标示六神与星煞。
- 在卦的吉凶判断层面，伏神本来是不存在的，它并不属于卦象的组成部分，只在卦中确实找不到用神了，才通过卦所在的卦宫套算出相应六亲的伏神，作为用神的替代品，所以像这类情况称为用神不上卦，而这类卦象往往会引起资深卦师的警觉与怀疑，卦象是反映问事者心念的信息载体，关注于问某事，但代表事情的用神却没有显露在卦中，这本身就是很不正常的事，不是摇卦人的心态出现变化，就是卦象将有另兆显现
- 在吉凶判断层面，其理论的特点是“严谨细致、泾渭分明”，各式理论的定义概念与应用范围都十分严格，丝毫不能混淆。
- 在吉凶判断层面，存在日墓理论却没有月墓理论；论日绊正确但论月绊却是错误的；同样是爻克日月的格局，可以说爻在月令上休囚，但却不能说爻在日令上休囚；动爻什么情形论有用、什么时候视为无用，都有严格的规范；理论中遍布真空假空、真破假破、真墓假墓、真进假退、真绝假绝等等鉴别套路。
- 吉凶判断层面，月令对爻的影响，只有旺相休囚，并不存在生旺墓绝的理论。日令对爻，虽然存在生旺墓绝的理论，但生旺墓绝的应用特征是“从于卦理”，出现理论冲突的话，生克冲合的卦理应被优先考虑
- 对于卦象分析，吉凶判断层面是属于静态分析（即时点分析），从摇卦成卦的那一刻起，就定格在卦成之时的日月与卦象基础上，分析其吉凶祸福，日月并不会随着预后的时日变换而相应转动

#### 细节层面

- 应期细节层面的理论，目的是为了达到准确分析所预测事情发生的具体时间、具体现状、具体过程、具体细节、相关信息、事后信息，以及如何趋吉避凶等等。简单的概括就是为了剖析事情发生的种种细节过程
- 用于应期细节分析层面的卦象，相对就完整得多了，除了主卦，不管动与否都完整显示变卦，伏爻是否为用神都要标示，甚至有些有作用的藏爻也须显示；年月日三柱显示完全，六神与星煞都详细排列
- 应期细节层面的理论特点却是“灵活飘逸、择象套用”，日月、五行、六亲、天干、地支、六神、星煞、卦辞、卦宫、十二宫等等，几乎每个信息符号都可以有很多层含义，你可以根据事情的客观状态，灵活地择象套用推理解剖，到了这个分析层面，在吉凶判断层面不允许存在的月墓、月绊说法都可以运用，只要卦象有分析的需要就行
- 应期细节分析层面，却是实实在在的动态分析。在分析应期推论细节的时候，卦中的日令月令，会随着时日的推移而相应变换，这样才可以准确预判出吉凶发生的具体时日，以及不同时期的吉凶细节描述。而随着时日推移的日令月令转变，为了更显预测实效，在变换运算上，又与正常的万年历日月转换方式略有差别，其简易公式为：“短事日转月不转；常事月转日不转；长事日月皆不转、只有太岁动”。往往时间跨度在一个月内的事称为短事；时间跨度在一年内的事称为常事；时间跨度在一年以上的事称为长事

##### 五行生克

- 水曰润下，火曰炎上，木曰曲直，金曰从革，土爰稼穑

- 相克：金（克）木， 木（克）土， 土（克）水， 水（克）火， 火（克）金

- 六亲相生相克（子孙、妻财、官鬼、父母、兄弟；旁者相生，隔者相克，也是循环不息）

##### 各神

- **世爻**：处在世位置上的爻，代表问卦人自己。特别对于问与己相关之事，世爻是卦断吉凶的分析核心之一。
- **应爻**：处在应位置上的爻，代表所占问之人事，也代表他人、特指之人事，一般作为用神的参考与辅助信息，应用于应期细节层面。
- **用神**：在卦中确定所占问人事的爻，代表事情的本身。用之于事，故为用神。用神也是吉凶判断层面的分析核心之一。（如问考试，父母爻便是用神）
- **元神**：生用神的爻。用神动力之根源，故为元神。（如父母为用神，官鬼生父母，官鬼爻便是元神）
- **忌神**：克用神之爻。为用神所畏忌，故为忌神。（如父母为用神，妻财克父母，妻财爻便是忌神）
- **仇神**：克制元神之爻。克用之源与用结仇，故为仇神。（如父母为用神，官鬼就是元神，子孙克官鬼，子孙爻便是仇神）

**用神体系关系（吉凶层速查）：**

```
        仇神 ──克──→ 元神 ──生──→ 用神 ←──克── 忌神
                      ↑                             
                   生用神                         
```

| 角色 | 与用神关系 | 吉凶层作用 |
| :-- | :-- | :-- |
| 用神 | 所问之事本身 | 分析核心 |
| 元神 | 生用神 | 生旺则吉助；被克则动力减 |
| 忌神 | 克用神 | 发力则凶 |
| 仇神 | 克元神 | 间接削弱用神 |
| 世爻 | 问卦人自己 | 与用神同为核心 |

- 问卦意念是谁的，就以谁为核心取用神——**自占**按自身事类取用（问财取妻财，问官取官鬼）；**代占**按被占之人事取用（占父母取父母，占领导取官鬼），与摇卦人身份无关。

##### 长生十二宫

- 长生十二宫于卦吉凶判断的应用（即五行的生旺墓绝，长生与帝旺代表旺相，墓是中性，绝代表衰相）
- 生旺墓绝在吉凶判断层面有个特征，就是“从于卦理”，一切卦理与之性质冲突，均是卦理优先舍己取它
- 四土爻本身就是藏气之墓库，金木水火之气均藏于此，本为库藏又何为其库？因此四土爻并没有墓，所以土爻遇辰土，只论扶旺进退而不能论墓
- 在吉凶判断层面，暂时只需掌握“**两墓二绝一生旺**”就可以
- **火爻**： 长生在寅；旺在午；墓在戌；绝在亥（实际需要记忆的只是**巳午火爻墓在戌**，其余在吉凶层面不用理会）
- **金爻**： 长生在巳；旺在酉；墓在丑；绝在寅（实际需要记忆的只是**酉爻绝在寅**，其余在吉凶层面不用理会）
- **木爻**： 长生在亥；旺在卯；墓在未；绝在申（实际需要记忆的只是**寅卯木爻墓在未**，其余在吉凶层面不用理会）
- **水土爻**：长生在申；旺在子；墓在辰；绝在巳（吉凶层面实际须要记忆的只是**土爻长生在申、旺在子；子爻绝在巳**就可以）
- 生旺墓绝中长生与帝旺是旺相的标志，墓是中性的，在衰与不衰之间摇摆，而绝是衰相的象征。

**吉凶层面精简记忆法（"两墓二绝一生旺"）说明：**

- 火爻长生在寅、木绝在申等，与五行生克重复，吉凶层面可**省略**——寅本生火即旺，申本克木即衰。
- 与卦理冲突时**从于卦理**：如申金绝在寅，但申寅又相冲，论冲不论绝；金长生在巳，但火克金，论克不论长生；辰为水库而土克水，遇水爻舍墓而论克。
- 四土爻本身为库藏，**土爻没有墓**，土遇辰只论扶旺进退不论墓。
- 掌握上述精简规则后，吉凶定性可一针见血，不必死记十二宫全部位置。

**"两墓二绝一生旺"口诀卡（吉凶层只需背这五条）：**

| 口诀 | 内容 |
| :-- | :-- |
| 一生 | **丑辰未戌**四土爻，长生在**申** |
| 一旺 | **辰未戌**三土爻，帝旺在**子** |
| 两墓 | **寅卯木**墓在**未**；**巳午火**墓在**戌** |
| 两绝 | **子水**绝在**巳**；**酉金**绝在**寅** |

> 一句话：**吉凶层只记两墓、两绝、一生、一旺**——其余与五行生克重复或与卦理冲突者，从于卦理，可省略。

##### 卦种

**卦种**：根据问卦意念或卦象成像特征，预先设定的分析种类；不同卦种会影响吉凶层面的套路选择，甚至影响取用神的理念。

| 卦种 | 说明 | 学习阶段 |
| :-- | :-- | :--: |
| **事卦** | 最常见，反映事情本身信息 | 基础 |
| **吉凶卦** | 分吉凶判断、细节应期两个层面 | 基础 |
| **自占卦** | 自己摇卦问己事；世爻之动只趋向自身变爻 | 基础 |
| **静卦** | 无明动与变卦，有特殊吉凶公式 | 基础 |
| **应期卦** | 只反映应期，无吉凶定性层面 | 进阶 |
| **心态卦** | 显示心态信息（又名忧患卦）；分明/暗心态卦 | 进阶 |
| **代占卦** | 代问他人；分主动/被动、主控/失控代占 | 进阶 |
| **连占卦** | 同一意念重复再占；分客观/主观连占 | 进阶 |
| **近占卦** | 问短期事，公式套路有迁就改变 | 进阶 |
| **远占卦** | 问长远期事，公式套路有迁就改变 | 进阶 |
| **独发卦** | 仅一明动爻，唯一动变有特殊意义 | 进阶 |
| **独静卦** | 仅一爻安静，唯一静爻为应期细节关键 | 进阶 |
| **全动卦** | 六爻皆动，事必折腾，世用之动为吉凶关键 | 进阶 |
| **时效卦** | 全程受特殊时空约制，吉凶有别常理；分日令/月令/终身时效卦 | 深入 |
| **指导卦** | 专门发出趋吉避凶指引 | 深入 |
| **灾卦** | 就重大损害或意外提前预警 | 深入 |
| **时运卦** | 占问时运变化，动兆发利弊方向 | 深入 |
| **选择卦** | 就决策、取舍、选择而占，动兆有特殊运动方向 | 深入 |
| **竞争卦** | 带争夺竞争性质，分析带对比特殊性 | 深入 |
| **另兆卦** | 占此应彼，解读难，对轨要求高 | 深入 |
| **兼应卦** | 显本题吉凶同时释放事外提示 | 深入 |
| **太过卦** | 某元素出现无法与现状对轨的绝对倾向；分太旺卦/太衰卦 | 深入 |
| **双核卦** | 吉凶成败与特指人事物关联，分析由两点重心变三点重心 | 深入 |
| **现状卦** | 专门反映现状，信息属现状点非趋势点 | 深入 |
| **自然卦** | 无欲无求、隔岸观火意念下形成；**唯一没有特定用神**的卦种 | 深入 |
| **影像卦** | 模拟过去/目前/未来某时点事物影像信息 | 深入 |

- **注：** 心态卦、应期卦、时效卦、连占卦、近远占卦、独发/独静卦、指导卦、灾卦、时运卦、选择卦、竞争卦、另兆卦、兼应卦、太过卦、双核卦、现状卦、自然卦、影像卦等，属**深入进阶内容**，本著不重点披露；初学以事卦、吉凶卦、自占卦、静卦为主即可。

**几种基础卦种的关键区分：**

| 卦种 | 核心特征 | 取用与层面 |
| :-- | :-- | :-- |
| **事卦** | 最常见；占某人/某事/某物 | 以代表所问之事的爻为用神；含吉凶+应期两层 |
| **吉凶卦** | 问成败祸福 | 重吉凶定性，应期其次 |
| **应期卦** | 问何时发生 | **无吉凶定性层**；前提通常是成败已定，只问何时了结；动兆不论生克吉凶，只作应期信号 |
| **自占卦** | 自己起念问己事 | 按自身事类取用神；世动只向变爻 |
| **代占卦** | 代他人起念 | 按被占者取用神；分主动/被动、主控/失控四种 |
| **静卦** | 无明动、无变卦 | 吉凶公式与动卦**大相径庭**，须专章学习 |

**代占卦四种类型（进阶预习）：**

| 类型 | 含义 | 解卦要点 |
| :-- | :-- | :-- |
| **被动性代占** | 当事人委托代摇，意念源于当事人 | 可视为当事人自占 |
| **主动性代占** | 代占者自身好奇或需求而起卦 | 需判断主控/失控 |
| **失控性代占** | 对所占之事无主导权，仅关心关注 | 以被代占者为核心；世爻非重点（占主动代占主流） |
| **主控性代占** | 实质由代占者主导决策 | 动兆可能指向用神，也可能指向世爻——若指向世爻，须改按**自占**思维定位六亲 |

- **事卦 ⊃ 吉凶卦 / 应期卦**：事卦是大类；其中问趋势结局属吉凶卦，问时间点属应期卦（如问何时结婚、何时下雨、占寿元等）。

##### 应君世应

- **应爻**：是指处在应位位置上的爻，代表所占问之人事，与问卦人的问卦意向。我们知道用神代表占问事情本身，用于吉凶判断层面的分析；应爻也可代表事情本身，但信息应用与用神有所区别，它只在细节应期层面上作为用神的辅助分析对象，如问事用神不空应爻空，应期上可以把应爻空作为事情的应期来分析，但在吉凶判断上却不能随意放大应爻的作用，一般只重点分析用神就可以。
- **君爻**：是指处在卦中第五爻位置上的爻，细节分析层面上，它代表占问之人的真实心态与意图。若把一个卦比喻成为一个人的身体，则君爻正好处在人的心脏位置。同时君爻也可以是卦中趋势关键因素的细节信息点，就象一台机器的控制按纽一样。
- **世应关系**：对于世应关系的代表意义，也应用于应期细节层面居多。其中的世爻在细节层面，往往代表现状存在信息，或者事后的最终结果信息。而世应元素作为一个整体，它们共同构成了事情本身的关联与因果信息。应期上，应生世可意味着事情快而顺利；应克世则意味事情受到阻滞；世克应可意味事情的应期较为迟缓；世生应可意味事情显拖沓未理顺；细节分析上，世应爻的相互生克也可看作是彼此的地位、状态、关系等等，如问占与他人关系，应克世代表对方约束着你，应生世代表对方有求于你，但这些都应立足于细节层面的分析，而不能将这些信息故意放大到吉凶判断层面，作为吉凶判断的依据。世应关系只在细节上说明事情的静态状况，或应期缓急的一种信息提示符号，本身并不具备主导吉凶的功能。

**世应关系速查（仅细节/应期层）：**

| 关系 | 应期含义 | 细节含义（例：问与人关系） |
| :-- | :-- | :-- |
| 应生世 | 快而顺利 | 对方有求于你 |
| 应克世 | 受阻滞 | 对方约束着你 |
| 世克应 | 应期较缓 | 你约束/压制对方 |
| 世生应 | 拖沓未理顺 | 你迁就/付出于对方 |

##### 刑害

- 相刑的信息，多只应用于卦象应期与细节的分析。寓意尴尬、隔膜、约束、拘束、禁锢、病痛、遭遇刑祸、判罚等细节信息。
- **注：** 下列相刑与目前社会流传的主流学说（丑未戌三刑、午亥辰酉四刑）有所区别；经反复验证，**古筮真诠体系采用下列版本**，因信息分布更有规律。细节层面须灵活择象，不必死记"无礼之刑"等固定名目。
- **丑未辰戌四土互刑又自刑**。如丑与辰、辰与未、丑与未互刑等等，互刑是外界因素构成的相刑。又如辰与辰、未与未等等构成自刑，自刑是自身因素构成的刑。卦中也可整体构成四刑局，则刑的信息更为明显。
- **巳申寅三互刑**。如巳与申互刑、巳与寅互刑、寅与申互刑，在卦中也可以整体构成三刑局，则刑的信息更为明显。
- **午亥酉三互刑**。如午与亥互刑、午与酉互刑、酉与亥互刑，在卦中也可以整体构成三刑局，则刑的信息更为明显。
- **子卯互刑**。如子刑卯，或卯刑子。
- 共有六对爻是互为相害的，分别是：**寅巳相害；卯辰相害；未子相害；申亥相害；酉戌相害；丑午相害**。
- **相害规律：** "与他合者相冲、与他冲者相合"——相合者如朋友，相冲者如仇敌；与友见仇、与敌交好，则彼此猜忌、芥蒂、难融通，寓意**相互拖累、欲合难融欲离难舍**。
- **相害只用于细节分析层面，不用于吉凶定性层面。**

##### 星煞

- **星煞群：** 古论星煞累加有上百个，经长期实践筛选出日常应用频率较高的**十三个实用型星煞**，融入专业排盘，组成"星煞群"，专用于细节定位分析（其中**谋星**为朱辰彬原创发明）。
